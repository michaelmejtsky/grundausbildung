🔔 Grundausbildung – Push-Schlüssel

Hier kannst du die benötigten VAPID-Schlüssel direkt in deinem Browser erzeugen. Die Schlüssel werden nicht an GitHub oder andere Server übertragen.

Wichtig: Der private Schlüssel wird nur einmal am Bildschirm angezeigt. Gib ihn niemals in einen GitHub-Code, Chat oder eine E-Mail ein. Trage ihn ausschließlich in Cloudflare als Secret ein.

Eintragen als mailto:deine-arbeitsmail@domain.at (mit deiner tatsächlichen E-Mail-Adresse).

Die öffentliche und private VAPID-Angabe gehören zum selben Schlüsselpaar. Bei einem späteren Wechsel müssen sich Geräte neu anmelden.
